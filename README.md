# 🤖 Jarvis AI Assistant

A powerful Python-based AI Voice Assistant inspired by Jarvis. This assistant can execute voice commands, launch applications, browse websites, perform searches, manage files, and interact with AI models for intelligent conversations.

## 🚀 Features

### 🎙 Voice Control
- Speech-to-Text
- Voice Command Recognition
- Natural Language Interaction

### 🤖 AI Assistant
- Intelligent AI Conversations
- Question Answering
- General Chat Support

### 💻 Application Control
- Open Notepad
- Open Calculator
- Open Browser
- Launch Installed Applications

### 🌐 Web Operations
- Open Google
- Open YouTube
- Open GitHub
- Search the Web

### 📂 File Management
- Create Files
- Manage Directories
- Storage Operations

### 📸 Utilities
- Take Screenshots
- Get Current Time
- Get Current Date

## 🛠 Installation

### Clone Repository

```bash
git clone https://github.com/Cyberspace-tech/jarvis-ai.git
```

```bash
cd jarvis-ai
```

### Create Virtual Environment

```bash
python -m venv venv
```

### Activate Virtual Environment

Windows:

```bash
venv\Scripts\activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run Project

```bash
python main.py
```
